# 테이블 뷰어 — `camera_info.password` 마스킹

- 일시: 2026-08-06 09:59
- 대상: `SettingMain/src/db/tableQuery.ts`, `SettingMain/test/dbRoutes.test.ts`
- 요청: "카메라 테이블의 password 는 `***` 로 출력해줘"

## 1. 배경 — 왜 구멍이었나

카메라 편집 경로(`GET/POST/PUT /api/db/cameras`)는 이미 비밀번호를 내보내지 않는다.
`dbRoutes.ts` 의 `publicCamera()` 가 `password` 를 떼고 `hasPassword: boolean` 만 실어 보낸다.

그런데 **테이블 뷰어**(`POST /api/db/query` → `tableQuery.runQuery`)는 `SELECT *` 결과를
그대로 돌려주고 있었다. 같은 값이 한쪽 문은 잠기고 다른 문은 열려 있던 상태다.
화면(`dbtable.js`)에서 가리는 방법도 있었으나 그러면 **HTTP 응답 본문에는 평문이 그대로**
남아 개발자도구·프록시·로그에 노출된다. 그래서 서버에서 가린다.

## 2. 설계

`tableQuery.ts` 에 "가림 열(masked column)" 개념 하나를 도입하고, 그 개념에서
세 가지 결과를 함께 끌어낸다. 마스킹만 하면 검색이 오라클로 남기 때문이다.

| # | 규칙 | 이유 |
|---|------|------|
| ① | 응답 값에서 `***` 로 치환 | 요청 사항 |
| ② | 자유 텍스트 훑기 대상에서 제외 | `password LIKE '%secre%'` 로 행이 잡히면 한 글자씩 되물어 원문 복원 가능 |
| ③ | `textColumn`·`conditions.column`·`orderBy` 로 지정 불가 (400) | ②와 같은 오라클. 명시 지정 경로도 막아야 완결된다 |

**빈 값은 가리지 않는다.** `''` 를 `***` 로 만들면 비밀번호가 없는 카메라(시뮬레이터 등)를
있는 것처럼 보이게 한다. 이는 `publicCamera` 의 `hasPassword` 가 알려 주는 정보와도 어긋난다.

**열 자체는 지우지 않는다.** `result.columns` 에 `password` 는 그대로 남는다 —
화면이 머리와 칸을 `columns` 로 그리므로 열을 빼면 표가 어긋난다.

## 3. 변경 내용

### `SettingMain/src/db/tableQuery.ts`

```ts
const MASKED_COLUMNS: Partial<Record<ViewableTable, readonly string[]>> = {
  camera_info: ['password'],
};
const MASK = '***';
```

- `runQuery()` 시작부에 `const masked = MASKED_COLUMNS[table] ?? []` 추가.
- 자유 텍스트: 열 미지정 시 `columns.filter((c) => !masked.includes(c))` 만 훑는다.
- `requireColumn(columns, name, table, masked)` — 인자 하나 추가. 가림 열이면
  `"{table}.{column} 은 가려진 열이라 검색·정렬에 쓸 수 없습니다"` 400.
  호출 3곳(textColumn·conditions·orderBy)이 모두 이 함수를 지나므로 한 자리에서 막힌다.
- 반환 직전 `rows.map((row) => maskRow(row, masked))`.

### `SettingMain/test/dbRoutes.test.ts`

`describe('camera_info.password 는 가려서 나간다')` 3건 추가.
픽스처의 `cam-a` 는 비밀번호 `secret`, `sim-1` 은 빈 문자열이라 두 경우가 한 번에 잡힌다.

1. 값 있으면 `***`, 없으면 `''`. `columns` 에 `password` 유지. 응답 전문에 `secret` 부재.
2. `text: 'secret'` → `total: 0` (훑기 제외 확인).
3. `textColumn`/`conditions`/`orderBy` 로 `password` 지정 → 각각 400 + `/가려진 열/`.
