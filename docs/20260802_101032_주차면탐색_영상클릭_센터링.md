# 주차면 탐색 영상 클릭 센터링

## 변경 내용

주차면 탐색 페이지의 카메라 뷰에 화면 중앙 고정 십자와 마지막 클릭 위치 원 표시를 추가했다. 십자는 마우스 포인터 모양이 아니라 영상 오버레이이므로, 커서를 움직여도 영상 중앙에 그대로 남는다.

## 사용 방법

1. `주차면 탐색` 페이지를 연다.
2. BackendCore 카메라를 선택하고 `활성으로 선택`을 누른다.
3. 영상 `시작` 또는 `스냅샷 1장`을 눌러 영상을 표시한다.
4. 중앙에 고정된 라임색 십자를 확인한다.
5. 중앙으로 가져올 대상 위치를 마우스 왼쪽 버튼으로 클릭한다.
6. 클릭점에 황색 원이 표시되고 BackendCore에 point-centering 명령이 전달된다.

## 안전 규칙

- 왼쪽 버튼 이외의 클릭은 무시한다.
- 영상 비율 때문에 생기는 검은 여백은 클릭해도 PTZ 명령을 보내지 않는다.
- 활성 BackendCore 카메라가 아니면 실제 명령 대신 상태줄에 안내를 표시한다.
- 센터링 요청 중 중복 클릭은 무시한다.

## 구현 경계

클릭은 실제 이미지 표시 영역을 기준으로 Hucoms/BackendCore 논리 프레임 `1920×1080` 좌표로 변환된다. UI가 팬·틸트 각도를 계산하지 않고, 기존 BackendCore `POST /api/center`가 점을 화면 중앙으로 이동시킨다.
