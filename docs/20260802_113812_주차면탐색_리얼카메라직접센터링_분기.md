# 주차면 탐색 리얼카메라 직접 센터링 분기

## 확인된 상태

BackendCore `http://192.168.0.220/barocalory`는 안전한 GET에서 정상 응답했다. 다만 `/api/cctv/capabilities`는 BackendCore의 active device가 `sim-cam-03`임을 반환했다. 따라서 BackendCore mode는 SettingMain에서 고른 리얼카메라2를 자동 선택하지 않는다.

## 변경

주차면 탐색 영상 좌클릭의 제어 경로를 checkbox로 분기했다.

| BackendCore 사용 | 요청 | 대상 |
|---|---|---|
| OFF | `POST /api/ptz/center` + 선택 `cameraId` | SettingMain에서 고른 실제 Hucoms 카메라 |
| ON | `POST /api/center?useBackendCore=1` | `192.168.0.220/barocalory`가 현재 활성화한 장비 |

따라서 리얼카메라2의 실제 PTZ를 움직이려면 우선 checkbox를 끄고 리얼카메라2를 선택한 후 영상 클릭을 사용한다. BackendCore를 통한 이동이 필요하면 BackendCore 자체에서 active device를 리얼카메라2로 바꿔야 한다.
