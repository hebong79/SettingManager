# 카메라 제어·주차면 탐색: 센터링 완료 원 중앙 표시

## 변경 내용

카메라 제어 페이지와 주차면 탐색 페이지에서 영상 왼쪽 클릭으로 PTZ 센터링에 성공하면, 황색 원을 클릭했던 위치가 아니라 **영상의 화면 중앙**에 표시하도록 변경했다.

고정 라임색 십자와 황색 원은 모두 영상 중앙에 겹칩니다. 이는 선택한 대상이 PTZ 이동 후 현재 화면 중앙으로 옮겨졌다는 완료 표시입니다.

## 동작 순서

1. 영상의 대상 위치를 마우스 왼쪽 버튼으로 클릭한다.
2. 센터링 명령이 서버/카메라에 전달된다.
3. 명령이 성공하면 클릭 대상이 화면 중앙으로 이동한다.
4. 황색 원이 중앙 십자 위치에 표시된다.

명령이 실패하면 새 황색 원을 표시하지 않아 성공한 것처럼 오인하지 않게 한다.

## 대상 화면

- 카메라 제어: `http://localhost:13030/`
- 주차면 탐색: `http://localhost:13030/discovery`

## 확인 방법

브라우저에서 `Ctrl+F5`로 강력 새로고침한 후 영상을 시작한다. 대상 위치를 왼쪽 클릭했을 때, 성공 후 작은 황색 원이 라임색 십자와 함께 정확히 영상 중앙에 표시되는지 확인한다.

## 검증

- TypeScript typecheck 통과
- Vitest 14개 파일, 234/234 통과
- build 통과

실운영 PTZ 이동은 안전상 자동 테스트하지 않았다.
