# 주차면 탐색 클릭 센터링 HTTP 400 호환성 수정

## 현상

주차면 탐색 영상에서 클릭하면 다음 오류가 나타났다.

```text
backend-core HTTP 400
Your client has issued a malformed or illegal request.
```

## 수정

SettingManager가 BackendCore로 보내는 센터링 요청을 좌표만이 아니라 다음처럼 완전하게 전달하도록 변경했다.

```json
{
  "x": 1400,
  "y": 800,
  "frameWidth": 1920,
  "frameHeight": 1080,
  "speed": 50
}
```

- `x`, `y`: 클릭 위치를 1920×1080 논리 화면으로 변환한 좌표
- `frameWidth`, `frameHeight`: 원본 논리 프레임 크기
- `speed`: Hucoms/BackendCore의 기본 PTZ 이동 속도

누락된 기본값을 엄격하게 처리하는 BackendCore, 프록시, 카메라 구성에서도 요청 형식이 명확해진다.

## 마스터 확인 방법

1. `SettingMain` 콘솔을 확인한다.
   - nodemon이 `src/` 변경을 감시하므로 보통 자동 재시작된다.
   - 자동 재시작 로그가 없으면 콘솔에서 `rs`를 누르거나 `Ctrl+C` 후 `npm start`를 다시 실행한다.
2. 브라우저에서 `Ctrl+F5`를 눌러 강력 새로고침한다.
3. `http://localhost:13030/discovery`를 연다.
4. BackendCore 카메라를 활성으로 선택하고 영상을 시작한다.
5. 안전한 영상 지점을 왼쪽 클릭한다.

정상이라면 오류 HTML 대신 황색 클릭 원이 나타나고, 클릭 대상이 중앙으로 이동합니다.

## 검증

- TypeScript typecheck 통과
- Vitest 13개 파일, 232/232 통과
- build 통과

실운영 카메라 이동은 자동 테스트에서 수행하지 않았다. 이 수정 후에도 같은 HTML 400이 반복되면 실제 BackendCore의 배포 URL/역프록시/버전 차이를 로그로 확인해야 한다.
