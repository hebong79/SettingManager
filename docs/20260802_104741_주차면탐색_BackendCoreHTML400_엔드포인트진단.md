# 주차면 탐색 BackendCore HTML 400 진단

## 결론

화면의 오류는 브라우저 클릭 좌표 오류가 아닙니다. `backend-core HTTP 400`의 본문이 JSON이 아닌 Apache HTML이므로, 주차면 탐색에서 설정한 BackendCore 제어 URL이 현재 BackendCore API endpoint와 다르거나, 그 앞의 역프록시가 API POST를 받지 않는 상태입니다.

최신 BackendCore의 `POST /api/center`은 JSON 오류를 반환해야 합니다. 따라서 HTML 400은 SettingManager가 기대하는 BackendCore API 계약과 맞지 않는 서버에 도달했음을 의미합니다.

## 변경된 안내

이제 오류가 나면 원문 HTML 대신 아래처럼 안전한 endpoint와 설정 방향을 표시합니다.

```text
backend-core endpoint http://호스트:포트/api/center가 HTML HTTP 400을 반환했습니다.
이 카메라의 제어 URL은 BackendCore API 기준 URL이어야 하며 Hucoms CGI 또는 RTSP URL이 아닙니다.
```

## 마스터 조치

1. `http://localhost:13030/options`를 엽니다.
2. 주차면 탐색에서 사용한 카메라를 찾습니다.
3. 종류가 `backend-core`인지 확인합니다.
4. **제어 URL**에 카메라의 CGI 주소 또는 RTSP 영상 주소가 아닌, `BackendCore`가 실제로 실행 중인 base URL을 입력합니다.
   - 올바른 예: `http://BackendCore호스트:포트`
   - 잘못된 예: `http://카메라IP/cgi-bin/...`, `rtsp://...`, MJPEG 영상 주소
5. 적용 후 카메라 제어/주차면 탐색에서 연결 테스트를 하고, 브라우저를 `Ctrl+F5`로 새로고침합니다.

URL의 실제 호스트와 포트는 환경마다 달라 추측해서 적지 않습니다. 새 오류에 표시될 `backend-core endpoint ...` 한 줄(비밀번호 없이 origin/path만 표시됨)과 BackendCore 콘솔 로그를 보내면 다음 단계에서 정확한 URL을 확정할 수 있습니다.
