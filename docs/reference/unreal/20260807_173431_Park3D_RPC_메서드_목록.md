## 1. 서버 개요

| 항목 | 값 |
|---|---|
| 프로토콜 | JSON-RPC 2.0 over HTTP (POST) |
| 엔드포인트 | `http://0.0.0.0:13510/rpc` |
| 카탈로그 | `GET /rpc/catalog` (= `system.catalog`) |
| 구현 | `Rpc/RpcServerSubsystem.cpp` — `UGameInstanceSubsystem`, 월드 기동 시 자동 시작 |
| 인증 | `AllowAnonymous` — 토큰·Origin·루프백 검사 전면 우회(연구 단계 정책) |
| 등록 메서드 | **82개** (도메인 79 + system 3) |
| 실동작 | **72개** (미구현 10개 제외) |

**포트 결정 우선순위**: `-RpcPort=` 커맨드라인 > `Save/Config/config_pmaker.json` 의 `rpc_port` > `DefaultGame.ini [RpcServer] Port` > 기본 `13510`. `-RpcPort=0` 은 서버를 아예 띄우지 않는다.

**호출 조건**: 대부분의 도메인 메서드는 **월드가 로드된 상태**(PIE 또는 `-game`)를 요구한다. 에디터만 떠 있으면 매니저를 못 찾아 실패한다. 캡처 계열은 실제 RHI가 필요해 `-nullrhi` 에서 동작하지 않는다.

**MJPEG 스트림은 별도 채널**이다. 카메라별 독립 HTTP 포트(기본 13601~13650, `config_pmaker.json` 의 `cam_port_min/max`)를 쓰며 이 RPC 목록에 포함되지 않는다.

## 2. 공통 규약

- **좌표**: `pos` 는 `{x, y, z}`, **z = 높이(UE Z)**, x·y = 지면. 단위는 미터.
- **camId**: 1부터. `carNameId` 는 문자열 식별자.
- **파일 경로**(save/load 계열): `fullPath` 를 주면 그대로 사용, 없으면 `path`(디렉터리) + `fileName` 조합, 둘 다 없으면 기본 경로.
- **에러**: 미구현은 `-32000` + 사유 문자열. 도메인 실패는 `FailDomain` 메시지.
- ⚠ 표시는 **등록만 되어 있고 호출하면 실패**하는 메서드다.

## 11. 조회·호출 방법

**카탈로그**
```
GET http://localhost:13510/rpc/catalog
```

**호출**
```
POST http://localhost:13510/rpc
{"jsonrpc":"2.0","id":1,"method":"cam.getPTZ","params":{"camId":1}}
```

**Claude(MCP)에서**: JSON-RPC-HTTP를 직접 못 붙이므로 `park3d-rpc-mcp` 브리지를 경유한다. 툴 2개 — `park3d_catalog`(목록), `park3d_rpc(method, params)`(호출).

## 12. 검증 상태

- 메서드 이름 82개는 **실행 중인 인스턴스의 `system.catalog` 응답**이다.
- 파라미터 표는 각 모듈 `.cpp` 의 `RpcParam::Require*` / `Get*` 호출을 정적 분석해 뽑았다. **개별 호출로 검증하지는 않았다.**
- 미구현 10건은 소스의 `NotImplemented` / `FailDomain("미구현")` 문자열로 확인했다.
