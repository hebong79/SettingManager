# 영상 클릭 센터링 및 조준 오버레이

## 목적

카메라 제어 화면에서 영상의 정확한 중앙 위치를 십자로 확인하고, 화면의 특정 지점을 왼쪽 클릭해 그 대상이 화면 중앙으로 오도록 PTZ를 조준한다.

## 사용자 동작

1. 카메라 제어 페이지에서 `시작` 또는 `스냅샷 1장`을 눌러 영상을 표시한다.
2. 영상 정중앙의 라임색 십자는 현재 화면의 중심점이다.
3. 중앙으로 가져오려는 지점을 **마우스 왼쪽 버튼으로 한 번 클릭**한다.
4. 클릭한 지점에 황색 작은 원이 남고, 해당 점을 화면 중앙에 놓도록 카메라가 이동한다.
5. 이동 완료 후 현재 PTZ 값과 하단 상태 메시지가 갱신된다.

## 구현 원칙

- 화면 표시 크기나 비율이 달라도 실제 렌더링된 이미지 기준으로 클릭 좌표를 변환한다.
- 영상의 검은 여백(letterbox/pillarbox)을 클릭하면 명령을 보내지 않는다.
- Hucoms는 제조사 공식 `ptz_centering.cgi`의 point mode를 사용한다. 브라우저는 팬/틸트 각도를 직접 계산하지 않는다.
- 이미 센터링 명령을 보내고 정착을 기다리는 동안에는 중복 클릭 명령을 막는다.
- 해당 기능을 지원하지 않는 카메라는 명시적으로 오류(HTTP 501)를 반환한다.

## API

`POST /api/ptz/center`

요청:
```json
{ "cameraId": "카메라ID", "x": 0, "y": 0 }
```

- `x`: 0~1920 정수
- `y`: 0~1080 정수

응답은 사용한 논리 점, 현재/정착 PTZ 및 `settled` 상태를 포함한다.
