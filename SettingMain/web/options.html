카메라 제어 옵션

코어 구현-

경로와 화면은 어느 쪽을 골라도 같습니다 — 무엇을 할 수 있는지만 달라집니다.
자체 코어는 아직 센터링만 지원합니다. 탐색·캘리브레이션·호밍은 backend-core 경유를 고르세요.
지원하지 않는 기능은 조용히 넘기지 않고 사유와 함께 거절합니다.

BackendCore주차면 탐색 전용

주차면 탐색 화면에서 BackendCore 사용 체크박스를 켰을 때만 이 주소의 API를 사용합니다. 카메라의 CGI 제어 URL·RTSP 영상 URL은 여기에 입력하지 마세요.

기기 (장치)-

활성 기기는 카메라 제어 페이지가 기본으로 사용하는 카메라입니다.

ID 만 정하면 등록됩니다. 나머지 접속 정보는 아래 편집 폼에서 채우세요. ID 는 나중에 바꿀 수 없습니다.

기기 편집저장 안 됨

「이 기기 적용」을 누르면 config/config.json 에 즉시 저장됩니다(재기동 불필요).
비밀번호는 저장된 값이 화면으로 돌아오지 않습니다 — 비워 두면 기존 비밀번호가 유지되고, 바꿀 때만 입력합니다.
영상 URL 은 스킴이 경로를 가릅니다 — rtsp:// 는 ffmpeg 전사, http:// 는 연속 MJPEG 중계(UE 시뮬 직결 포트), 비우면 스냅샷 폴링.
「연결 테스트」는 저장 없이 지금 화면의 값으로 PTZ 를 한 번 읽어 봅니다 — 카메라를 움직이지 않습니다.
